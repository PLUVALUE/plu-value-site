# Site plu-value.fr

- `out/` : le site publié (Netlify publie ce dossier à chaque envoi sur `main`).
- `base.py`, `pages.py`, `pages2.py`, `blog.py`, `build.py` : le générateur. `python3 build.py` reconstruit `out/`.
- `out/site.css` et `out/media/` sont édités à la main (non régénérés).
- Articles : liste `ARTICLES` dans `blog.py` ; `drafts/` contient les brouillons importés tels quels.

Règles de contenu : aucune promesse de gain, de prix ou de délai ; toujours « sous conditions suspensives » ; PLU Value ne vend pas et ne publie pas d'annonces ; chaque chiffre est sourcé.
